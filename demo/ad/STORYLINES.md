# Cognita ad: storylines

Source footage: `demo/live/assets/live-take.mp4` (real Claude Code session, 85 s). Every number below comes from that take.

## A. "Without asking" (recommended)

Device: the result first. Form: cut on the beat, punch-ins on the real footage.
The ad opens on the risk, not the logo: the Access card glowing red with "Runs without asking: read .env secrets". Then the fix lands live, and the payoff is the pane showing it blocked.

- First 2 s: black, one line types "Your agent can read your .env." then a hard cut to the real red Access card.
- Beats: hook (.env risk) → "35k tokens before you type a word" → deny rule added live → re-check, blocked → trim "-1,080 tokens" → end card `/plugin install cognita@cognita`.
- Look: the existing dark terminal ground, Cognita orange, Caveat hand-drawn circles from the demo.
- Sound: music bed cut on the beat, a click on each punch-in, a low hit on the red card.

## B. "35k"

Device: a number lands. Form: type carries the argument.
Giant kinetic numbers fill the frame (35k, 540 tools, 9.1k never used, -1,080), each one cuts to a half-second flash of the real screen that proves it.

- First 2 s: "35,000" fills the frame, ticks up from 0, subtitle "tokens before you type a word".
- Beats: 35k → 540 tools → 9.1k unused → 1 risky action → fix → end card.
- Look: black ground, oversized Roboto numbers, orange accents, footage only as proof flashes.
- Sound: punchy beat, every number lands on a downbeat.

## C. "Dive into the pane" (bold)

Device: the object is the explanation. Form: an endless zoom.
The camera never cuts: from the whole terminal it dives into the Cognita pane, into the Context card, into the unused skills, out to Access, and out to the install line.

- First 2 s: wide view of a plain Claude Code session, `/cognita` typed, the camera starts pushing in.
- Beats: session → pane → Context → Access → Agents → Pressure → end card.
- Look: real footage only, scale and blur as the camera material.
- Sound: rising synth bed, whoosh per dive.
